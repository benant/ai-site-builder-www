    자주 묻는 질문

    정말 기획과 시안까지 무료인가요?

    네. 카테고리·템플릿 선택, 정보 입력, AI 기획서, 디자인 시안 3종 제공까지는 비용이 들지 않습니다. 시안 중 하나를 선택하고 결제하실 때만 비용이 발생합니다.

    결제는 어떻게 하나요?

    PayPal로 진행됩니다. 시안 선택 후 대시보드(저장소 이슈)에서 최종 견적과 함께 PayPal 결제 버튼을 제공하며, 결제 확인 즉시 작업이 자동으로 시작됩니다.

    GitHub 계정이 꼭 필요한가요?

    네. 의뢰 접수 시 GitHub 사용자 이름이 필요하고, 완료 후 고객 전용 저장소의 공동작업자로 초대되기 때문입니다. 무료로 누구나 만들 수 있습니다.

    제 사이트 내용이 다른 사람에게 보이지 않나요?

    고객별로 전용 비공개(private) 저장소를 새로 만들고, 그곳에 고객님만 초대됩니다. 다른 고객의 의뢰 내용과 겹치지 않습니다.

    수정은 어떻게 요청하죠?

    납품 후 2주간, 고객 전용 저장소에 "[REVIEW]" 형식의 이슈를 남기시면 AI가 분석해 반영하고 커밋으로 알려드립니다. 범위를 크게 벗어나는 변경은 추가 견적을 안내해 드립니다.

    시안이 마음에 안 들으면?

    피드백을 남겨주시면 최대 2회까지 시안을 다시 생성해 드립니다. 그래도 진행하지 않으셔도 되며, 이 경우 비용은 청구되지 않습니다.
